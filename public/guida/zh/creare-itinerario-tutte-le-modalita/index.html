创建行程：所有模式与所有选项

行程选项卡（«智能行程规划»）拥有十个入口。你在这里可以找到全部内容、步骤、表单中的每个字段、默认值以及费用。通用规则：创建行程每消耗 10 积分/天（1–30 天），扣费前总是会显示确认提示。

译自意大利语。截图、视频和示例显示的是意大利语界面。

与 WIP 对话

  1. 点击“和 WIP 聊聊”。
  2. 输入（例如：“在里斯本待三天，十月份，不要博物馆”）并点击发送，或者使用麦克风（“正在听…”）。
  3. Wip 每次只问一个问题并朗读回答（“WIP 说话：开启/关闭”开关会记住你的选择）。
  4. 当确定了目的地和天数后，会显示带有“生成行程”和“修改一下”的摘要。
  5. 点击“生成行程”后，数据将进入表单并开始常规生成，同时会进行积分确认。
  • 收集：目的地（多个城市用“和”连接）、天数、月份、兴趣、预算、节奏、同行者、仅限免费、时间和特殊要求。
  • 费用：每 10 条消息 3 积分（需确认），外加行程每天 10 积分。需要 AI 同意。最多 20 次对话。

📅 最佳出行时间

  1. 点击“何时出发”。
  2. 输入城市（“输入城市…”）并点击 OK。
  3. 将打开带有两个视图的标签页：年份和月份。

部分：数据概览、概览、网络建议、旅行者体验、逐月指南、携带物品、最佳游玩时间、注意事项、适宜游泳的月份、近年来与平均水平的对比、来源。按钮 PDF、聆听、“与其他城市比较”。数据来源：NASA POWER 2001–2020 平均值。完全免费；AI 分析需要登录。

从我的收藏中选择

  1. 点击“从我的收藏生成”（如果没有地点，则显示“旅行日记空空如也”和探索地图按钮）。
  2. 勾选地点（显示“已选择 N 个元素”计数器）。
  3. 选择时间段和三个复选框（活动、导览、免费），如果需要，还可以选择高级选项。
  4. 点击“优化旅行路线”（至少 1 个地点）。
  • 你无需选择天数：系统会按地点总数除以 3 并向上取整来计算（3 个地点 = 1 天；10 个地点 = 4 天）。
  • 如果地点距离市中心超过 150 公里，系统会询问你是否继续。

半径探索：3 个替代方案

  1. 点击“半径探索”。
  2. 选择出发点：城市、地址或“使用我的位置”。
  3. 选择半径 (km)：100 / 300 / 500 或自定义数值（1–5000）；默认值为 300。
  4. 选择兴趣：🏛️ 艺术与文化 · 👨‍👩‍👧 家庭 · 🍷 美食与美酒 · 🌊 海滩 · ⛰️ 山脉 · 🌳 自然 · 💆 放松 · 🧗 冒险。
  5. 设置持续时间（1–7 天或输入“gg”最高可达 30 天）、时间段、时间以及三个复选框。
  6. 点击“寻找3个替代方案”（免费）。
  7. 阅读三个方案（“这里有一些建议”）：标题、描述、天数、途经点。“再生成 3 个方案”是免费的。
  8. 点击你喜欢的方案：将显示确认提示（10 × 天数）并开始实际生成。

滑动选择：滑动并选择

  1. 点击“滑动选择”。
  2. 填写：目的地、天数（1–7）、时间段（用于活动卡片）、景点类型（🏛️ 博物馆 · 🗿 纪念碑 · ⛪ 教堂 · 📍 景点 · 🍕 美食 · 🌿 自然 · 🛍️ 购物；无默认选择）。
  3. 点击“开始滑动！”（免费）。
  4. 对于每张卡片：点击 ❤ 或向右滑动表示保留，点击 X 或向左滑动表示放弃。撤销可返回上一张。点击“阅读全部 / 收起”可展开文本。顶部显示 N / 总数计数器以及带有已选项目的心形图标。
  5. 开启活动或导览后，牌组中最多会混入 5 张“🎫 真实活动”卡片。
  6. 从 1 个途经点开始，点击“修改途经点 (N)”：对每个途经点可进行🔄 替换或✕操作。
  7. 点击“生成包含 N 个途经点的路线”：确认（10 × 天数）并开始生成。

团队旅行

角色步骤
组织者（需要登录）“创建房间” → 选择**目的地**、**天数**（1–30）、**月份**（可选）、**你的名字** → **“创建房间”** → 获取 **6 位数 PIN** → **“邀请小组”**（链接 wip.guide/?groupplan=PIN） → 查看“收到的投票：N” → **“小组偏好合成”** → **“应用到表单并生成 →”**：表单将自动填写，由**你来生成**并支付正常费用。
参与投票者（无需账号）“我有 PIN” → 输入 PIN → **“进入房间”** → 姓名；**你对什么感兴趣？**（艺术、美食、自然、冒险、购物、摄影）；**预算**；**节奏**；**必看景点**和**避开景点**（可选，200 个字符以内）→ **“发送我的偏好”**；然后是“修改我的投票”。
  • 最多 12 名参与者，房间开放 7 天，每个设备一票（会更新，不会重复）。
  • 无 AI 合成：选择获得至少 2 票（或得票最多的 3 个）的兴趣、中位数预算、最常见的节奏；“必看”和“避开”将进入特殊要求。付款前检查所有内容：合成功能仅负责填写表单。
  • 房间和投票完全免费；仅由生成者付费。

WIP 不做什么（以免产生误解）

  • 没有针对单个路线带公开链接的“分享路线”按钮：可以通过 PDF、.ics 日历、故事或团队旅行进行分享。
  • “何时出发”不会创建路线。
  • 在“从我的收藏生成”中无法选择天数。

常见问题

如果我不知道去哪里，应该选择哪种模式？

«半径探索»（3个免费备选项）或自动模式下的当季灵感。

我可以免费试用吗？

可以：最佳出行时间、3个半径探索备选项、Swip、群组房间和书库在生成之前都是免费的。

最多几天？

30天；如果是多座城市，天数会在各个城市之间分配。
