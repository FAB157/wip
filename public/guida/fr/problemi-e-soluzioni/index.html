Problèmes et solutions : pourquoi ça ne démarre pas, pourquoi je ne vois pas…

Quand quelque chose ne fonctionne pas, la cause est généralement l'une de celles-ci.

Traduit de l'italien. Les captures, vidéos et exemples montrent l'app en italien.

L'audioguide ne se lance pas

  • La catégorie est désactivée dans Configuration (Profil › CONFIGURATION › Catégories Audioguide). Les joyaux parlent de toute façon.
  • La précision GPS est inférieure à 50 m : l'app ne lance rien. Sortez à l'air libre.
  • Vous avez déjà écouté le lieu au cours des dernières 24 heures (« Réinitialiser l'historique » dans Configuration).
  • Vous êtes sur le web avec la page fermée ou l'écran éteint : l'app est nécessaire.
  • Vous n'avez ni crédits ni Day Pass pour le guide complet : le teaser se lance quand même.
  • Mode Semi-Automatique : touchez vous-même « Écouter ».
  • Le lieu appartient à une catégorie sans audioguide (Établissements, Services, Familles, Thématiques, Community, Biens culturels).

Le navigateur ou le circuit se tait

  • Le navigateur multi-étape du tour nécessite le Day Pass.
  • WipNav est réservé aux piétons ; pour la voiture, utilisez Google Maps.
  • Écran éteint, l'app est nécessaire avec l'autorisation de localisation « Toujours ».
  • Si vous vous trompez de route écran éteint, le recalcul s'effectue en rouvrant l'app.

Je ne trouve pas un lieu

  • La recherche trouve des villes, pas des noms individuels : cherchez la ville et activez le bon filtre.
  • Certaines choses n'apparaissent qu'avec plus de zoom (« zoomez pour les voir »).
  • Il vous manque la catégorie dans la barre : ajoutez-la depuis ＋ Autre.
  • Vous avez trouvé une erreur ? Depuis la fiche, touchez « Vous avez remarqué une erreur ? Signalez-la ».

Hors ligne

Les packs de zone et le Day Pass fonctionnent hors ligne dans l'app. Téléchargez d'avance, avec le Wi-Fi, les itinéraires et les zones dont vous avez besoin (Profil › Mes téléchargements).

Questions fréquentes

Le GPS est toujours imprécis en ville ?

Entre les hauts bâtiments, la précision diminue : attendez quelques secondes à l'air libre.
